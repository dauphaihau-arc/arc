# Rename Or Reorder

See the [design](../README.md) and [flow index](../flow.md).

1. Load current IDs and versions.
2. Keep existing IDs while changing option names, value labels, or presentation positions.
3. Submit the complete matrix with the same selection identities. Omit inventory edits when none are intended.
4. Verify that variant and inventory IDs are unchanged and physical quantities have not moved.

For example, correcting `Blue` to `Navy` for the same goods is a rename. Converting a blue shirt's stock pool into red shirts is not.
